# 個人互動網頁平台：全端資料庫功能擴充計畫書

本計畫書旨在規劃如何將現有的「個人網頁與互動遊戲專案」進一步升級，藉由導入後端關聯式資料庫（Database），設計並實現三個具備高實用性與技術含量的全端核心模組：**小遊戲全域排行榜**、**訪客互動留言板**，以及**真實網站流量分析與視覺化看板**。

---

## 一、 系統架構設計 (System Architecture)

升級後的系統將採用標準的三層式架構（3-Tier Architecture），前端、後端與資料庫獨立分工，確保系統的可維護性與可擴充性：

```
                    ┌─────────────────────────────────┐
                    │ 前端客戶端 (React & HTML5/JS)   │
                    │ - 個人首頁 / About 自傳頁       │
                    │ - 各類小遊戲 / 留言板 / DataViz │
                    └────────────────┬────────────────┘
                                     │
                        (發送 HTTP Fetch 請求)
                                     │
                                     ▼
                    ┌─────────────────────────────────┐
                    │ 後端伺服器 (Node.js Express)    │
                    │ - RESTful API 路由與商務邏輯    │
                    │ - 流量監控攔截器 (Logger)       │
                    └────────────────┬────────────────┘
                                     │
                        (檔案讀寫 / SQL 查詢)
                                     │
                                     ▼
                    ┌─────────────────────────────────┐
                    │ 資料儲存層 (SQLite / JSON DB)   │
                    │ - 排行榜 / 訪客留言 / 流量日誌  │
                    └─────────────────────────────────┘
```

*   **資料庫技術選型建議**：
    *   **本機開發與學術報告**：使用 **SQLite** 或 **JSON 檔案型資料庫**。本專案目前採用檔案型 JSON 資料庫以求極高的移植性；未來可直接藉由 SQLite 升級為標準關聯式資料庫。
    *   **雲端部屬**：若部屬至雲端平台（如 Render, Heroku），可切換至 PostgreSQL 或 MySQL。

## 二、 三大模組詳細規劃與設計

### 模組一：小遊戲「全站排行榜」與「戰績紀錄」(Game Leaderboard & Match DB)

此模組將原本存在於瀏覽器暫存中的遊戲結果，上傳並持久化於資料庫中，實現真正的全網玩家競爭與對戰紀錄。

#### 1. 核心功能
*   **結算自動上傳**：玩家在「踩地雷」過關時、或「打磚塊」結束時，系統自動將玩家名稱、通關時間或分數上傳至後端。
*   **動態前十名排行榜**：首頁或遊戲選單頁面可動態向後端獲取各遊戲的 Top 10 排行榜，激發使用者互動意願。
*   **棋類對局紀錄**：記錄每次對局的勝負、日期與棋譜內容（可用於賽局重播）。

#### 2. 資料庫結構 (db/game_records.json)
每一筆紀錄包含：唯一的 `id`、遊戲名稱 `game_name`、玩家名稱 `player_name`、分數 `score`、通關時間 `completion_time_seconds` 以及建立時間 `created_at`。

---

### 模組二：履歷訪客留言板與聯絡表單 (Visitor Message Board DB)

將網頁底部的聯絡方式升級為具有資料庫儲存與管理員審核機制的「互動留言牆」。

#### 1. 核心功能
*   **訪客留言提交**：任何進入網頁的訪客（包括面試官），可在表單內填寫稱呼、聯絡信箱以及留言內容並提交。
*   **留言牆即時展示**：審核通過的留言會以卡片牆形式呈現在網頁上。
*   **後台管理功能**：站長（林彥廷）能登入查看未公開留言、撰寫回覆（Reply）或刪除留言。

#### 2. 資料庫結構 (db/messages.json)
每一筆留言包含：唯一的 `id`、訪客名稱 `visitor_name`、聯絡信箱 `visitor_email`、留言內容 `message_text`、站長回覆 `reply_text`、是否公開 `is_visible` 以及建立時間 `created_at`。

---

### 模組三：流量監控與數據視覺化看板 (Web Analytics & DataViz DB)

此模組將使「作品 C (資料視覺化)」大幅升級，從原本抓取第三方模擬資料，改為**動態呈現您個人網頁的真實訪客數據**。

#### 1. 核心功能
*   **無感流量收集**：前端在路由切換或使用者啟動小遊戲時，自動向後端發送輕量級的造訪紀錄（Page View）。
*   **流量指標統計**：後端對資料庫中的紀錄進行彙整，計算每日造訪人數 (UV)、各頁面點擊率 (PV) 以及最受歡迎的遊戲排行。
*   **視覺化圖表渲染**：在 `data-viz.html` 頁面上，使用 Chart.js 動態渲染自己網站的「流量趨勢折線圖」與「小遊戲點擊比例圓餅圖」。

#### 2. 資料庫結構 (db/visit_logs.json)
每一筆日誌包含：唯一的 `id`、造訪路徑/動作 `page_path`、瀏覽器類型 `browser_type`、訪客 IP 的單向雜湊值 `ip_hash`（保護隱私）以及訪問時間 `visit_time`。

## 三、 專案預期成效 (Expected Deliverables)

1.  **實務開發能力展示**：
    實作了**全端資料串接、SQL/JSON 資料庫設計、API 設計與防錯降級機制**，能高度證明具備全端工程師（Full-Stack Developer）的實務開發能力。
2.  **網頁互動性增強**：
    個人網頁不再只是單向的資訊展示，而是一個能與訪客產生實時互動（留言、排行榜競逐）、並能分析網站流量的動態平台。
